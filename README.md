# Acervo

Document search system for law firms. Solo-built, currently in development.

Law firms accumulate thousands of case documents. Acervo lets a lawyer find the right one by meaning, not just by exact keywords.

> This repository is a showcase. The source code is private.

## What it does
- Semantic + keyword search over case documents
- Web interface for searching and browsing results
- Runs fully containerized with Docker

## Stack
- **Backend:** Python, FastAPI, SQLAlchemy (async), Alembic
- **Database:** PostgreSQL with pgvector (vector similarity search)
- **Frontend:** HTML, CSS and JavaScript (no framework)
- **Infra:** Docker
